Privacy

When on, pasted links are stripped of tracking identifiers and downloads avoid cookies, caches, and watch-history reporting. Turn it off only if a stubborn video refuses to download — some age-restricted or login-walled videos need a regular browser-like session.

Desktop

How the app behaves on your computer.

Library backup Download database backup Your whole conversion history in one file. A backup is also saved automatically before any database upgrade (kept: last 5).

Duplicate Prevention

Before converting a track, the app checks whether a file with the same name already exists in the output folder. If it does, the track is skipped instead of being downloaded again.
