This is a local tool

This audio converter runs entirely on your computer. There's no cloud service or remote server involved — everything happens locally.

If you need help, please check the troubleshooting section below.

Troubleshooting

FFmpeg must be installed and in your system PATH.
For macOS: brew install ffmpeg
For Windows: Download from https://ffmpeg.org
For Linux (Ubuntu): sudo apt install ffmpeg

The video may have been removed or is private.
YouTube changes frequently — update yt-dlp: pip install --upgrade yt-dlp
Try a different video to confirm the tool works.

The track may be private or removed.
Update yt-dlp to fix compatibility issues: pip install --upgrade yt-dlp
Make sure you're using the full track URL (not just the artist page).

Check the output path in Settings — it must exist and be writable.
Make sure there are no spaces or special characters in the path if possible.

Large files take time to download and convert.
The app has a 5-minute timeout for downloads.
Try shorter videos or check your internet connection.
